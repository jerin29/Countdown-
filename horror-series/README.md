## Suggested production pipeline (per episode)

1. **Storyboard:** One sketch per row of the script table (about 12–15 frames).
2. **Character sheets:** Generate once with the prompts in the bible and reuse them for consistency.
3. **Backgrounds:** Only 6 locations for the whole series, so build them once and reuse them.
4. **Voice:** Record the dialogue first (an animatic is timed to the voice).
5. **Animatic:** Storyboard frames plus voice plus temp music, timed to exactly 1:30.
6. **Animate:** Limited animation works well for horror. Use slow push-ins, holds and small movements.
7. **Sound:** Add the BGM cues and SFX, then mix to −14 LUFS.
8. **End card:** The same chime and hum every time.
